# Яндекс Товары: Отключить аккаунт — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Товаров:** Удаляет сохранённый токен Яндекс Товаров с диска; токен из переменной окружения не трогает.

Техническое имя: `logout`

## Какую задачу решает

> Я хочу отключить Яндекс Товары.

Удаляет сохранённый вход из диалога: файл с токеном стирается с диска, и сервер перестаёт им пользоваться.

## Когда использовать

Используйте эту возможность, когда нужно отключить аккаунт или войти под другим логином Яндекса (после `logout` вызовите [start_login](./start-login.md) заново).

## Что нужно передать

Параметры не нужны.

## Что вернёт

Компактный JSON: `removed` (был ли удалён сохранённый токен), заметку и `envTokenStillSet` — задан ли токен переменной окружения, который этот инструмент не трогает.

## Что изменится в Яндекс Товарах

Инструмент удаляет локальный файл `credentials.json` с сохранённым токеном. Данные в Яндекс Товарах не меняются; чтобы снова пользоваться инструментами, подключение придётся установить заново.

## Пример запроса

> Отключи Яндекс Товары.

## Возможные ошибки и ограничения

Токен, заданный переменной окружения `YANDEX_MERCHANTS_OAUTH_TOKEN`, не удаляется — его нужно убирать из конфигурации AI-приложения вручную. Доступ, выданный приложению, остаётся активным на стороне Яндекса: отозвать его можно в [Яндекс ID](https://id.yandex.ru/security).
