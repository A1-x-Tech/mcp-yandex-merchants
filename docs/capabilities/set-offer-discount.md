# Яндекс Товары: Установить скидку на товар — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Товаров:** Устанавливает скидку: price — цена со скидкой, discount_base — старая цена, которая покажется зачёркнутой (тот же POST /offer-prices/updates, но discount_base обязателен).

Техническое имя: `set_offer_discount`

## Какую задачу решает

> Я хочу установить скидку на товар.

Устанавливает скидку: price — цена со скидкой, discount_base — старая цена, которая покажется зачёркнутой (тот же POST /offer-prices/updates, но discount_base обязателен).

## Когда использовать

Используйте эту возможность, когда нужен результат «Установить скидку на товар» без ручной работы в интерфейсе Яндекс Товаров. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `feed_id` — **обязательно**. Идентификатор фида (feedId из list_feeds).
- `offer_id` — **обязательно**. Идентификатор предложения из фида (id в YML, до 50 символов).
- `price` — **обязательно**. Цена в рублях (валюта всегда RUR), больше 0.
- `discount_base` — **обязательно**. Старая цена (зачёркнутая), обязательна и строго больше price.

## Что вернёт

Ответ API: { status: "OK" } либо { status: "ERROR", errors: [...] }.

## Что изменится в Яндекс Товарах

Инструмент изменяет реальные данные Яндекс Товаров так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Установить скидку на товар в Яндекс Товарах. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Скидка должна быть не меньше 5% и не больше 95% — проверяется до запроса, иначе API вернёт 400 Bad Request. Валюта всегда RUR.

Доступ также зависит от прав токена, квот и ограничений исходного API.
