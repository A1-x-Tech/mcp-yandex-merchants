# Яндекс Товары: Список товарных фидов — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Товаров:** Возвращает список товарных фидов, доступных текущему OAuth-логину: { status, feeds: [{ feedId, feedUrl }] }.

Техническое имя: `list_feeds`

## Какую задачу решает

> Я хочу посмотреть товарных фидов.

Возвращает список товарных фидов, доступных текущему OAuth-логину: { status, feeds: [{ feedId, feedUrl }] }.

## Когда использовать

Используйте эту возможность, когда нужен результат «Список товарных фидов» без ручной работы в интерфейсе Яндекс Товаров. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

Параметры не нужны.

## Что вернёт

Возвращает список товарных фидов, доступных текущему OAuth-логину: { status, feeds: [{ feedId, feedUrl }] }.

## Что изменится в Яндекс Товарах

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть товарных фидов в Яндекс Товарах. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Точка входа для всех остальных инструментов — их параметр feed_id берётся из feedId этого ответа. Больше API про фиды ничего не отдаёт: ни статуса фида, ни списка предложений (создание/удаление фида — только через кабинет или Вебмастер).

Доступ также зависит от прав токена, квот и ограничений исходного API.
