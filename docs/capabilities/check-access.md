# Яндекс Товары: Проверка токена и доступа — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Товаров:** Диагностика подключения: выполняет тот же GET /feeds-info и возвращает { ok, feedsCount } либо { ok: false, error }.

Техническое имя: `check_access`

## Какую задачу решает

> Я хочу проверить токен и доступ.

Диагностика подключения: выполняет тот же GET /feeds-info и возвращает { ok, feedsCount } либо { ok: false, error }.

## Когда использовать

Используйте эту возможность, когда нужен результат «Проверка токена и доступа» без ручной работы в интерфейсе Яндекс Товаров. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

Параметры не нужны.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Товарах

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Проверить токен и доступ в Яндекс Товарах. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Отдельного ping-эндпоинта в API нет. Если ok: false — проверьте, что OAuth-токен выдан со scope products:partner-api под тем логином, который загружал фид, и что права на сайт подтверждены в Вебмастере (API открывается через несколько часов после подтверждения).

Доступ также зависит от прав токена, квот и ограничений исходного API.
