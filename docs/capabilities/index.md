# MCP-возможности Яндекс Товаров

Каталог содержит 13 публичных страниц — по одной для каждого зарегистрированного MCP-инструмента (tool) репозитория `mcp-yandex-merchants`. Страницы начинаются с задачи пользователя, объясняют результат и отдельно показывают, изменит ли вызов реальные данные.

Используйте этот каталог для выбора готовой возможности. Полные схемы параметров и ответы API остаются в [техническом справочнике](../TOOLS.md).

## Подключение аккаунта

- [Статус подключения](./auth-status.md) — Показывает, есть ли токен, откуда он взят (переменная окружения или сохранённый вход) и когда истекает. **Воздействие:** только чтение.
- [Начать подключение Яндекс Товаров](./start-login.md) — Первый шаг входа из диалога: возвращает ссылку на страницу Яндекс OAuth, без правки конфигурации и без перезапуска клиента. **Воздействие:** только чтение.
- [Завершить подключение Яндекс Товаров](./finish-login.md) — Обменивает код подтверждения на токен доступа, сохраняет его локально (0600) и сразу проверяет живым запросом. **Воздействие:** изменяет данные.
- [Отключить Яндекс Товары](./logout.md) — Удаляет сохранённый токен с диска; токен из переменной окружения не трогает. **Воздействие:** опасная операция.

## Фиды и доступ

- [Проверка токена и доступа](./check-access.md) — Диагностика подключения: выполняет тот же GET /feeds-info и возвращает { ok, feedsCount } либо { ok: false, error }. **Воздействие:** только чтение.
- [Список товарных фидов](./list-feeds.md) — Возвращает список товарных фидов, доступных текущему OAuth-логину: { status, feeds: [{ feedId, feedUrl }] }. **Воздействие:** только чтение.

## Видимость товаров

- [Скрыть предложение из Поиска](./hide-offer.md) — Скрывает одно предложение из Поиска по товарам (POST /hidden-offers), например когда товар закончился. **Воздействие:** изменяет данные.
- [Массовое скрытие предложений](./hide-offers.md) — Массово скрывает предложения из Поиска: от 1 до 500 за запрос (POST /hidden-offers). **Воздействие:** изменяет данные.
- [Возобновить показ предложений](./show-offers.md) — Возобновляет показ ранее скрытых предложений: от 1 до 500 за запрос (DELETE /hidden-offers с JSON-телом). **Воздействие:** изменяет данные.

## Дополнительные методы API

- [Прямой вызов Merchants API](./raw-request.md) — Запасной выход: прямой вызов любого пути партнёрского API Яндекс Товаров относительно базового URL (https://yandex.ru/products/api/ext/partner), например "feeds-info" или "offer-prices/updates". **Воздействие:** изменяет данные.

## Цены и скидки

- [Установить скидку на товар](./set-offer-discount.md) — Устанавливает скидку: price — цена со скидкой, discount_base — старая цена, которая покажется зачёркнутой (тот же POST /offer-prices/updates, но discount_base обязателен). **Воздействие:** изменяет данные.
- [Изменить цену предложения](./set-offer-price.md) — Изменяет цену одного товарного предложения (POST /offer-prices/updates c одним элементом). **Воздействие:** изменяет данные.
- [Массовое обновление цен](./update-offer-prices.md) — Массово обновляет цены: от 1 до 2000 предложений одним запросом (POST /offer-prices/updates). **Воздействие:** изменяет данные.
