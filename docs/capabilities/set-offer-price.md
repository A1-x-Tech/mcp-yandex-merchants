# Яндекс Товары: Изменить цену предложения — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Товаров:** Изменяет цену одного товарного предложения (POST /offer-prices/updates c одним элементом).

Техническое имя: `set_offer_price`

## Какую задачу решает

> Я хочу изменить цену предложения.

Изменяет цену одного товарного предложения (POST /offer-prices/updates c одним элементом).

## Когда использовать

Используйте эту возможность, когда нужен результат «Изменить цену предложения» без ручной работы в интерфейсе Яндекс Товаров. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `feed_id` — **обязательно**. Идентификатор фида (feedId из list_feeds).
- `offer_id` — **обязательно**. Идентификатор предложения из фида (id в YML, до 50 символов).
- `price` — **обязательно**. Цена в рублях (валюта всегда RUR), больше 0.
- `discount_base` — **необязательно**. Цена до скидки (зачёркнутая), больше price; скидка 5–95%.
- `pay_by_price` — **необязательно**. Спеццена при выполнении условия оплаты (целое, в рублях); только вместе с pay_by_condition.
- `pay_by_condition` — **необязательно**. Условие оплаты для спеццены: yandex_pay, fast_payment_system или ozon_card; только вместе с pay_by_price.

## Что вернёт

Ответ API: { status: "OK" } либо { status: "ERROR", errors: [{ code, message }] } — проверяйте status.

## Что изменится в Яндекс Товарах

Инструмент изменяет реальные данные Яндекс Товаров так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Изменить цену предложения в Яндекс Товарах. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Валюта всегда RUR — подставляется автоматически. Опционально: discount_base — цена до скидки (покажется зачёркнутой; скидка должна попадать в 5–95%, иначе API вернёт 400), pay_by_price + pay_by_condition (только парой, вместе) — спеццена при условии оплаты. Если в фиде несколько предложений с одинаковым id, цена обновится только у первого. Лимит: 50 000 изменений цен в минуту.

Доступ также зависит от прав токена, квот и ограничений исходного API.
