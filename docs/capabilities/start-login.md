# Яндекс Товары: Начать подключение — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Товаров:** Первый шаг подключения из диалога: возвращает ссылку на страницу Яндекс OAuth — без правки конфигурации и без перезапуска клиента.

Техническое имя: `start_login`

## Какую задачу решает

> Я хочу подключить Яндекс Товары прямо из диалога.

Начинает вход в аккаунт Яндекса: возвращает ссылку на страницу Яндекс OAuth, которую нужно открыть в браузере. Настраивать переменные окружения и перезапускать AI-приложение не требуется.

## Когда использовать

Используйте эту возможность, когда сервер сообщает, что Яндекс Товары не подключены, или когда нужно войти под другим логином. Открыть ссылку нужно **строго под тем логином Яндекса, под которым загружен YML-фид** — токен другого логина не увидит ни одного фида. Токен выдаётся со scope `products:partner-api`.

## Что нужно передать

Параметры не нужны.

## Что вернёт

Компактный JSON: `authorizeUrl` (ссылка для пользователя), `clientId`, `expiresInMinutes` (код действует 10 минут) и подсказку о следующем шаге. Показанный после входа код подтверждения передаётся в [finish_login](./finish-login.md).

## Что изменится в Яндекс Товарах

Инструмент только читает данные или состояние подключения и не изменяет их. Ссылка строится локально, без сетевых запросов; вход происходит на стороне Яндекса.

## Пример запроса

> Подключи Яндекс Товары.

## Возможные ошибки и ограничения

Код подтверждения одноразовый и живёт 10 минут — если он не принят, вызовите `start_login` заново и попросите свежий. Повторный вызов заменяет предыдущий запрос на подключение. Сам по себе код бесполезен для постороннего: обменять его может только этот сервер (PKCE).
