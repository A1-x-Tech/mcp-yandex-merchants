# Яндекс Товары: Скрыть предложение из Поиска — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Товаров:** Скрывает одно предложение из Поиска по товарам (POST /hidden-offers), например когда товар закончился.

Техническое имя: `hide_offer`

## Какую задачу решает

> Я хочу скрыть предложение из Поиска.

Скрывает одно предложение из Поиска по товарам (POST /hidden-offers), например когда товар закончился.

## Когда использовать

Используйте эту возможность, когда нужен результат «Скрыть предложение из Поиска» без ручной работы в интерфейсе Яндекс Товаров. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `feed_id` — **обязательно**. Идентификатор фида (feedId из list_feeds).
- `offer_id` — **обязательно**. Идентификатор предложения из фида (id в YML, до 50 символов).
- `ttl_in_hours` — **необязательно**. Срок скрытия в часах, максимум 720 (30 дней). Без него предложение скрыто бессрочно.

## Что вернёт

Ответ API: { status: "OK" } либо { status: "ERROR", errors: [{ code, message }] }.

## Что изменится в Яндекс Товарах

Инструмент изменяет реальные данные Яндекс Товаров так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Скрыть предложение из Поиска в Яндекс Товарах. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

ttl_in_hours — необязательный срок скрытия в часах (максимум 720 = 30 дней, иначе ошибка INVALID_TTL); что делает повторное скрытие с новым ttl, дока API не описывает. Без ttl предложение скрыто до явного show_offers. Прочитать список уже скрытых предложений через API нельзя. Лимит: 50 000 операций скрытия/показа в минуту.

Доступ также зависит от прав токена, квот и ограничений исходного API.
