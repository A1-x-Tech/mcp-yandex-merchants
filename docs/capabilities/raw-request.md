# Яндекс Товары: Прямой вызов Merchants API — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Товаров:** Запасной выход: прямой вызов любого пути партнёрского API Яндекс Товаров относительно базового URL (https://yandex.ru/products/api/ext/partner), например "feeds-info" или "offer-prices/updates".

Техническое имя: `raw_request`

## Какую задачу решает

> Я хочу выполнить дополнительный запрос к API.

Запасной выход: прямой вызов любого пути партнёрского API Яндекс Товаров относительно базового URL (https://yandex.ru/products/api/ext/partner), например "feeds-info" или "offer-prices/updates".

## Когда использовать

Используйте эту возможность, когда нужен результат «Прямой вызов Merchants API» без ручной работы в интерфейсе Яндекс Товаров. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `path` — **обязательно**. Путь API относительно базового URL, например "feeds-info".
- `method` — **необязательно**. HTTP-метод; по умолчанию GET.
- `body` — **необязательно**. JSON-тело запроса в wire-формате API (для POST/DELETE).

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Товарах

Инструмент изменяет реальные данные Яндекс Товаров так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Выполнить дополнительный запрос к API в Яндекс Товарах. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Методы API: GET (feeds-info), POST (offer-prices/updates, hidden-offers), DELETE (hidden-offers). body отправляется как JSON в готовом wire-формате API (например { offers: [...] } или { hiddenOffers: [...] }) — без преобразований.

Доступ также зависит от прав токена, квот и ограничений исходного API.

## Связанные MCP-инструменты

Связанных специализированных инструментов в этой группе нет.
