# Яндекс Товары: Массовое обновление цен — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Товаров:** Массово обновляет цены: от 1 до 2000 предложений одним запросом (POST /offer-prices/updates).

Техническое имя: `update_offer_prices`

## Какую задачу решает

> Я хочу обновить цены нескольких предложений.

Массово обновляет цены: от 1 до 2000 предложений одним запросом (POST /offer-prices/updates).

## Когда использовать

Используйте эту возможность, когда нужен результат «Массовое обновление цен» без ручной работы в интерфейсе Яндекс Товаров. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `offers` — **обязательно**. Предложения с новыми ценами (1–2000 за запрос).

## Что вернёт

Ответ API: { status: "OK" } либо { status: "ERROR", errors: [{ code, message }] }; возможные коды: DUPLICATE_OFFER, INVALID_FEED_ID, INVALID_OFFER_ID, LIMIT_EXCEEDED, REQUEST_LIMIT_EXCEEDED (больше 2000 в запросе).

## Что изменится в Яндекс Товарах

Инструмент изменяет реальные данные Яндекс Товаров так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Обновить цены нескольких предложений в Яндекс Товарах. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Валюта всегда RUR. Лимит: 50 000 изменений цен в минуту. Для больших объёмов разбивайте на несколько вызовов.

Доступ также зависит от прав токена, квот и ограничений исходного API.
