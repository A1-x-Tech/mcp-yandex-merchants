# Яндекс Товары: Возобновить показ предложений — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Товаров:** Возобновляет показ ранее скрытых предложений: от 1 до 500 за запрос (DELETE /hidden-offers с JSON-телом).

Техническое имя: `show_offers`

## Какую задачу решает

> Я хочу возобновить показ предложений.

Возобновляет показ ранее скрытых предложений: от 1 до 500 за запрос (DELETE /hidden-offers с JSON-телом).

## Когда использовать

Используйте эту возможность, когда нужен результат «Возобновить показ предложений» без ручной работы в интерфейсе Яндекс Товаров. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `offers` — **обязательно**. Предложения, показ которых нужно возобновить (1–500 за запрос).

## Что вернёт

Ответ API: { status: "OK" } либо { status: "ERROR", errors: [...] }; коды: DUPLICATE_OFFER, INVALID_FEED_ID, INVALID_OFFER_ID, REQUEST_LIMIT_EXCEEDED.

## Что изменится в Яндекс Товарах

Инструмент изменяет реальные данные Яндекс Товаров так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Возобновить показ предложений в Яндекс Товарах. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Лимит: 50 000 операций скрытия/показа в минуту (общий с hide_offers).

Доступ также зависит от прав токена, квот и ограничений исходного API.
