# Яндекс Товары: Массовое скрытие предложений — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Товаров:** Массово скрывает предложения из Поиска: от 1 до 500 за запрос (POST /hidden-offers).

Техническое имя: `hide_offers`

## Какую задачу решает

> Я хочу скрыть несколько предложений.

Массово скрывает предложения из Поиска: от 1 до 500 за запрос (POST /hidden-offers).

## Когда использовать

Используйте эту возможность, когда нужен результат «Массовое скрытие предложений» без ручной работы в интерфейсе Яндекс Товаров. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `offers` — **обязательно**. Предложения для скрытия (1–500 за запрос).
- `ttl_in_hours` — **необязательно**. Срок скрытия в часах, максимум 720 (30 дней). Без него предложение скрыто бессрочно.

## Что вернёт

Ответ API: { status: "OK" } либо { status: "ERROR", errors: [...] }; коды: DUPLICATE_OFFER, INVALID_FEED_ID, INVALID_OFFER_ID, INVALID_TTL, LIMIT_EXCEEDED, REQUEST_LIMIT_EXCEEDED (больше 500 в запросе).

## Что изменится в Яндекс Товарах

Инструмент изменяет реальные данные Яндекс Товаров так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Скрыть несколько предложений в Яндекс Товарах. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Общий ttl_in_hours (максимум 720 часов) применяется ко всем предложениям запроса. Лимит: 50 000 операций скрытия/показа в минуту (общий с show_offers).

Доступ также зависит от прав токена, квот и ограничений исходного API.
